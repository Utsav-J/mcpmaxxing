# Teaching notes

- User already understands what MCP is and what it does. Skip protocol fundamentals unless they are needed to explain a project-specific choice.
- Focus lessons on what distinguishes this repo from a typical MCP: strict typed contracts, custom per-tool context metadata/resources, reference-host orchestration, local fixture behavior, revision-aware caching, and stateless HTTP transport.
- Ground explanations in this repository's server and agent implementation, and use short practical code-tracing exercises.
